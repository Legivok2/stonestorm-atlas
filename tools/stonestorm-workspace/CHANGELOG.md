# StoneStorm Workspace changelog

## 0.3.0 – Development preview

- Preserves normal game mode and the four-panel Mines workspace.
- Supports 4 × 1 and 2 × 2 layouts with locally saved panel preferences.
- Adds Hungarian and English localization for the Workspace toolbar, settings, and native application menu.
- Keeps the original embedded Stonestorm game interface unchanged.

This is a development preview, not a final release. No release date is announced for future workspaces.
